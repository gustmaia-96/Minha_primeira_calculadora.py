# Calculadora em Python

Este projeto contém uma calculadora básica desenvolvida em Python.

## Arquivos do projeto

- `calculadora_básica.py`: código principal da calculadora.
- `calculadora.sh`: script executável que roda a calculadora.
- `calculadora.txt`: passo a passo da atividade.

## Como executar o arquivo .sh

No terminal, dentro da pasta do projeto, execute:

chmod 744 calculadora.sh
./calculadora.sh
